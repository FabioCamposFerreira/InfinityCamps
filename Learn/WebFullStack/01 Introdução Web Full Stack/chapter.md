## Front-end vs Back-end

Front-end é o que o usuário vê. Back-end é o que processa, integra e entrega os dados.

```
Página / App  --requisições-->  API  -->  Banco
              <---respostas---
```

| Front-end | Back-end |
|---|---|
| HTML • CSS • JavaScript | Regras de negócio |
| Interface e layout | Integrações e APIs |
| Interação do usuário | Persistência dos dados |
| Experiência visual | |
